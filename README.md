# Multiple-linear-regression
Predicting business profitability using Multiple Linear Regression and key investment factors in AI-driven business analytics.

## Project Overview
This project aims to predict the profit of a business using Multiple Linear Regression. The model uses business investment data to understand how different spending factors are associated with company profit.

## Problem Statement
To develop a Machine Learning model that predicts business profit based on R&D Spend, Administration, Marketing Spend, and State.

## Domain
AI in Business Intelligence and Analytics

## Algorithm Used
- Multiple Linear Regression

## Dataset Description
The dataset contains the following features:

- **R&D Spend:** Amount invested in research and development.
- **Administration:** Amount spent on administrative activities.
- **Marketing Spend:** Amount invested in marketing.
- **State:** State in which the business operates.
- **Profit:** Company's profit; the target variable to be predicted.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Pickle (for model saving, if used)

## Project Workflow
1. Load the dataset.
2. Explore and preprocess the data.
3. Encode the categorical State feature.
4. Split the data into training and testing sets.
5. Train the Multiple Linear Regression model.
6. Predict business profit.
7. Evaluate model performance using suitable metrics.
8. Save the trained model for future use.

## Model Saving
The trained model is saved using Pickle for future predictions, if implemented in the project.

## Expected Outcome
The model estimates business profit based on the given spending variables and state. This project demonstrates how Machine Learning can support business analysis and data-driven decision-making.

## Current Status
Model creation and model saving are implemented. Deployment has not been completed.
